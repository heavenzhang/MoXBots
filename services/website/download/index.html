GET STARTED

按平台安装

macOS · Apple 芯片

  1. 01

    下载并解压

    下载 ZIP，解压后得到 MoXBots.app。请确认当前电脑使用 Apple 芯片。

  2. 02

    放入应用程序

    将 MoXBots.app 拖到“应用程序”文件夹。MoXBots 使用独立名称与配置，可与 MyAgents 并用。

  3. 03

    连接你的工作环境

    打开应用，在 AgentNet 中连接你使用的网络，再配置模型、创建 Agent。模型服务需要你自己的配置。

Windows · x64

  1. 01

    核对安装包

    下载 .exe 安装程序，先核对本页提供的 SHA-256。签名状态会在本页标明；若显示“未签名”，Windows 可能显示“未知发布者”或 SmartScreen 提示。

  2. 02

    运行安装程序

    仅在确认来源和校验值后运行，并按安装器提示完成安装。该包适用于 64 位 Windows。

  3. 03

    手动获取后续版本

    Windows 自动更新尚未开放。后续版本需要回到本页手动下载；不要把本安装包视为自动更新包。

BEFORE YOU INSTALL

安装前，了解这些。

这是正式发行版吗？+

这是试用版，仍在联调。签名、公证状态和具体版本以本页的构建信息为准；功能是否完成验收，以对应发行说明为准。

macOS 提示无法打开，怎么办？+

尚未经过 Apple 公证的试用包可能被系统阻止首次打开。请先核对来源、签名状态及 SHA-256；若系统仍拒绝打开，请联系提供者获取适用的发行包。

Windows 显示未知发布者或 SmartScreen 提示，怎么办？+

签名状态会在版本信息中标明。若显示“未签名”，Windows 可能显示未知发布者提示；请先核对本页 SHA-256，并只在确认来源可信且校验值相符后运行。

Windows 会自动更新吗？+

目前 Windows 自动更新端点尚未开放。请从本页手动下载后续版本，并核对每个版本各自的校验信息。

为什么可能出现系统凭据提示？+

已有网络连接可能需要首次迁移已保存的登录会话与设备签名钥。系统密码只在 macOS 的系统窗口输入，不要发给他人，也不要填到下载页面。免重复提示的实际验证结果会随版本说明提供。

Intel Mac 和 Linux 呢？+

本页当前提供 Apple 芯片 Mac 与 Windows x64 桌面试用包。Linux 轻量 Host 是独立的服务器程序，不包含在桌面包中。
