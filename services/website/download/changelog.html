0.5.11

最新 · macOS 自动更新

网页登录接续修复

  • 修复网页登录完成后桌面端无法接续的问题，兼容有限的客户端时钟偏差。
  • 恢复原账号和已有设备身份，客户端重启后保留登录状态。
  • 包含 0.5.10 候选中的会话、浏览器入口、排队消息与看板交互改进。

已通过签名、公证、真实登录与冷启动恢复、完整更新分发校验；不代表远程 Host 或所有模型场景均已验收。

0.5.10

未单独发布 · 已纳入 0.5.11

会话与任务交互改进

  • 完善浏览器资源入口，显示安装、启用、会话选择和连接状态。
  • 改进会话导航与页面缓存，保留草稿、附件、录音和等待中的交互。
  • 分开排队消息的编辑与取消，保护等待期间新增的输入。
  • 项目执行完成后进入待验收，归档可记录说明；会话按活动时间分组。

本候选没有单独推送为正式更新；网页登录接续修复请使用 0.5.11。

0.5.9

历史版本 · macOS 自动更新

看板与上下文恢复

  • 项目看板按状态组织任务，支持把空闲会话转为任务。
  • 侧栏和详情面板可调整宽度。
  • 改进下一步建议在正式会话中的入口和处理。
  • 改进长会话的上下文预算、压缩失败恢复及中断接续，防止重复执行已完成的操作。

Windows 构建候选不等于公开发行或实机运行验收。

0.5.8

历史版本 · macOS 自动更新

社区与更新恢复

  • 协作社区复用当前登录账号，支持查看话题、讨论和回复。
  • 浏览器完成登录后，客户端自动检测结果，减少手动检查。
  • 改进 Goal 和定时任务草稿的重启恢复，恢复后仍可继续编辑。
  • 改进结果展开、时间显示和重启确认；工作尚未安全结束时暂缓安装更新。

隔离环境中的社区和更新验收，不等于所有日常业务路径均已验证。

0.5.7

历史版本 · macOS 自动更新

账号与设备连接体验

  • 按登录账号和网络隔离设备身份，减少连接混用。
  • 同账号重新登录时恢复已有登记设备，取消登录时保留原身份。
  • 改善小窗口中的身份恢复弹窗和滚动访问。
  • 增加项目上下文与可选主备模型设置；主备模型默认关闭。

不同 Host、网络和模型场景仍有各自的配置及验收要求。

0.5.6

官网手动安装包 · 历史自动更新

阅读与更新体验

  • 支持界面字体缩放，按阅读习惯调整显示。
  • 改进 Goal 分组与长输出展示。
  • 统一 Bots Ready 与 Bots 网络入口和提示。
  • 下载与安装分开；保存、停止工作及重启使用明确确认，保护进行中的任务。

当前官网 macOS 手动安装包为此版本，使用 Developer ID 签名并通过 Apple 公证。

0.5.5

历史版本 · macOS 自动更新

任务看板与执行协作

  • 项目看板展示执行阶段、待办进度及子 Agent 状态，可返回原对话。
  • 生成灰色下一步建议，先接纳为可编辑草稿，再确认发送。
  • 审批执行方案前先展示方案正文，正文未加载时不能直接批准。
  • 统一 MoXBots 品牌与云端协作社区入口。

较早版本的部分原生交互和 Host 业务路径未覆盖完整验收。

关于发布与验收

“已发布”表示对应渠道可获取，不表示客户端已经自动安装。源码提交、签名公证、分发校验与真实业务验收分别记录。

Host 远程管理、模型执行、Windows 和自然会话续期等能力，不会因为 macOS 包已发布而自动视为验收通过。这里没有承诺所有连接场景均已验证。
