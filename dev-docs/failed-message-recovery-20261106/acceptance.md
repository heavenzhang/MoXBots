# MB-FAILED-MESSAGE-20261106

桌面发送失败的本地用户气泡原来只显示红字；下一次发送清掉全局错误后，旧失败仍留在列表且没有逐条恢复入口。两条同文输入不能按正文自动删并或重放。

本机日志确认用户截图对应的两次调用在任务识别阶段因模型无可用渠道返回503，未进入任务执行；后续另一次发送已有独立正式历史。上游渠道可用性不由本修复变更。私有日志、正文和请求ID不进入Git；历史失败气泡不被脚本删除或自动重发。

## 实现与边界

- Message 的失败行提供“重新发送 / 移除失败记录”。未知投递显示“发送状态待确认 / 检查发送状态”，保留原防重放记录。
- MessageList 的稳定转发读取最新回调，memo 行在能力变化时更新。
- Chat 从实时消息集合重新解析目标，走原普通发送与原读取恢复路径，保留当前草稿；不走 native rewind/retry。
- TabProvider 是本地失败投影的唯一修改入口。只移除指定的已确认未接纳记录；显式重发再次检查同一消息身份。已移除、发送中、未知或已有 canonical 创建（包括正文暂空）的请求均拒绝重发。
- 不改 canonical 历史、持久化格式、模型路由、业务执行、权限或凭据；没有数据迁移。
