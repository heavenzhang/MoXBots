# MoxBots 0.5.10

本版本候选包含 v0.5.9 后进入主干的桌面改进。其正式源码以通过版本 PR 和主干 CI 后记录的 v0.5.10 tag 为准；原生安装包与真实路径验收在更新服务发布前单独核验。

## 已合入改进

1. 浏览器使用入口更完整：对话和启动器可访问浏览器资源，区分安装、全局启用、当前会话选择和实际连接状态。
2. 网页登录回到客户端：客户端加入网页登录后的唤起与回调处理；当前公开服务没有可验证的构建身份，生产端支持尚未确认，因此暂不承诺生产登录回跳可用。旧 PKCE 轮询保留。
3. 原生帮助与反馈：已登录用户可从账号菜单打开反馈窗口；提交状态不确定时保留内容和请求标识以便安全重试。
4. 会话导航和缓存：侧栏用于页面导航，12 页是常规 FIFO 缓存目标；保存等待、活动录音等保护条件下可以临时超过目标。草稿、附件、IME 组合、问答、审批、录音和运行中任务受保护。
5. 排队消息操作：编辑和取消分开；失败显示服务端原因，编辑仅在撤回确认后恢复内容，并保留等待期间新增的输入和附件。
6. 项目看板：执行完成进入待验收；归档是接受动作，可记录说明；会话按活动时间分组。
7. 运行时可靠性：改进网络终态回执恢复、DSH 子任务审批上下文和资源选择，以及可复现构建校验。
8. 重启对话框调整危险操作的视觉层级。

## 服务与验收边界

当前公开 AgentNet 描述只声明 protocol 1 和 tls13-mtls，没有 typed-rpc、permit-v1、return-v1 或 return-resume-v1，也没有可验证的服务构建版本。生产终态返回恢复在正式服务声明并部署协议前不可用；网页登录回跳也未证实。客户端保留既有登录轮询和单轮结算回退，不会通过重放业务操作恢复结果。本次不部署 AgentNet 或 Host。

Browser、会话窗口、排队消息、看板和 DSH 的既有 headless、DOM、renderer、CI 记录不等于精确签名包的原生验收。正式发布记录会列明已通过的原生路径和仍待支持的能力。

兼容的桌面客户端可以在后台检查和下载更新；应用重启仍由用户在安全空闲时确认。本次发布不安装、退出或重启日常客户端。
