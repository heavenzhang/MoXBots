## 变更与证据

- GlobalSidebar 展开列表与原收起浮层增加“远程会话”，显示标题、来源、执行状态和独立未读点；聚焦/关闭仍由 App 的原 Tab controller 裁决。关闭观察不停止远端执行。
- 前台约1.5秒、后台约5秒，以前一请求完成为起点安排快照读取。切回、窗口恢复和网络恢复立即校准；同一观察循环不叠加请求，重复唤醒合并。
- 运行中观察回报当前账号认证代次；旧代次响应与其他账号/网络信息不能更新当前投影。去重优先当前认证代次，其次当前 Tab，保持其他入口顺序。
- 同网络远程请求串行，明确操作/回执优先于尚未开始的快照读取；排队取消与准入时重新鉴权。不打断已发出请求、不重试或重放写操作。
- 原 Tab codec 继续只保存 locator、scope、Session ID；不持久化聊天正文、名称、草稿或本次 UI 观察。重开后立即挂载后台观察并重读标题；来源名称在缺少当前元数据时使用原标识符。
