# MB-BOT-R2-20261101 · Bot 协作关系原型

承接 MB-BOT-R1-20261101。基于 MoXBots 的三栏布局、Sage 配色、名称/会话树与工作区目录表达。新建群组和任务流转为第二轮设计，不代表现有产品已接通执行链。用户实际页面截图仅作本机参考，没有放入此目录。

运行：直接打开 index.html，或 `python3 -m http.server 18749 --bind 127.0.0.1 --directory 本目录`。无外部依赖。浏览器仅向本机服务加载静态资源，演示状态保存在本页面专用 localStorage；“重置演示”只重置该原型数据。

## 可审阅路径

- “项目”入口 → 请假统计 / MoXBots：项目目标、成员、群组、任务、会话和目录集中展示；同一 Mino/小八可在两个项目出现。
- 从 MoXBots 项目与 Mino 新建会话，默认选择该项目；回到请假统计项目不会出现这个会话或它的任务。Bot 个人会话可不选项目。

- 群组初始 T01 待验收，T02 等待它验收；查看任务 → 返工并填写要求 → 提交演示回报 → 验收通过 → T02 解除依赖。
- T02 开始 → 交接给另一成员并说明原因 → 原任务编号保留、尝试号递增；刷新后记录和负责人保留。
- 打开 Bot → 新建会话 → 发送“请记住：…” → 点标题查看记忆；返回旧会话，消息独立。
- Bot 资料中换形象或名称；群组成员、发言者、任务负责人同步，工作区路径不变。
- 新建群组需 2–6 个已有 Bot；本原型提供 3 个可选 Bot。选择消息收件成员后发送，消息保留在当前群。
- 新建任务时填写负责人及验收要求。群组资料的“演示个人确认入口”进入单独 Bot 会话，确认不会在群内执行。
- 右侧工作区提供合成文件预览；深浅主题、窄屏 Bot 列表与任务抽屉可操作。

## 机制参考与取舍

2026-11-01 重读官方文档：[Bot 长期身份和图像](https://docs.x.ai/grok-bot/bots)、[群组与协作](https://docs.x.ai/grok-bot/chat-and-collaboration)。借鉴长期身份、同一 Bot 跨场景、群组点名与个人确认边界；MoXBots 的多会话、工作区和任务验收按现有产品保留、表达。

任务详情/验收/返工为 MoXBots 方案，未声称 Grok Bot 原样提供相同面板；未登录实测 Grok Bot。没有模拟云电脑、真实模型、权限准入、恢复、停止、并发执行和完整共享 Bot 机制，不用演示按钮替代这些能力。
