## V5 重点变化

统一输入区，文件/图片可点击预览；麦克风直接进入录入，转写可编辑并追加草稿；连续语音对话只生成示例。新建增加可选工作上下文，返回后保留Bot/模型/附件和草稿。会话内新增成果页、消息复制/引用、执行步骤和最新消息入口。

修复底栏挡住授权按钮、离开文件预览中断保存、文件讨论覆盖草稿、个人资料返回误丢和旧授权干扰新执行状态等问题。详见[本轮逐项验收](qa-v5/walkthrough-report.md)。

## 已实现的流程

- 会话：搜索、Bot/状态筛选、置顶、重命名、归档与恢复、停止、排队续写。会话固定归属原 Bot 和设备。
- 输入：新建与已有对话均有文件/图片选择、缩略图、移除、文字文件片段；最多5个附件、单个20MB。内容只在本页内存，没有上传服务器。支持附件单独发送。
- 模型：自动选择、Claude Sonnet、GPT、Kimi为示例配置；运行时暂停切换，选择只影响之后的消息。新会话采用个人偏好中的默认值，旧消息保留当时标签。
- 语音：麦克风直接录入/取消/结束/转写编辑/重新录入/带回草稿，以及连续语音对话示意。没有访问麦克风、录音、识别服务或真实音频播放。
- 下一步：按周报、会议、接口/日志等会话上下文给出规则式示例建议，点击只填草稿，不自动发送。
- 授权：从待处理筛选进入原会话，再看完整操作和范围；仅本次允许、拒绝与说明、提交禁用、结果回执和历史。支持文件创建与只读命令两类示例；过期/另一端已处理/设备离线的演示入口在个人中心→关于。
- 过期恢复：回会话带入重新发起草稿，发送后模拟新请求，需要重新确认。决定校验会话、请求及轮次身份，并防止重复提交。
- 成果：Markdown、PDF分页内容示意、CSV表格、ZIP不可预览状态；文件信息、保存中/成功/失败重试、个人保存记录和回原会话修改。
- 个人：头像入口、昵称/简介/头像样式、账号与安全、授权记录、手机/执行设备详情、平板授权移除示意、通知偏好与预览、文字大小、默认模型、Enter发送偏好、保存文件、帮助、反馈草稿、关于、退出并重新进入演示。

## 建议评审路径

1. 产品周报→查看并处理→允许本次操作→回原会话→PDF→翻页/文件信息/保存→回会话提修改。
2. 部署日志排查→查看请求命令→输入拒绝说明→拒绝→原会话确认回执；个人中心→账号与安全→授权记录。
3. 新建会话→添加文件/图片→选择模型→语音输入演示→转写带回草稿→发送；已有会话同样可用。
4. 会议纪要整理→下一步建议→确认只填草稿；成果→CSV或ZIP→回会话整理。
5. 头像→编辑资料、通知、偏好、设备；保存文件中重开成果；退出演示后重新进入。
6. 个人中心→关于→过期/已处理/离线/保存失败；检查不能重复批准、过期重发与保存重试。

## 范围与接续

数据只在当前页面内存，刷新恢复示例。附件留在浏览器，不持久存盘。PDF为HTML分页内容示意，不是真实PDF渲染器；保存仅登记示例状态，不下载到手机。语音、模型调用、身份认证、应用锁、通知、授权执行、设备撤销均未接真实服务。浏览器模板的系统键盘不是手机真机输入法。

本轮是独立本地设计原型目录，不是产品Git检出；未提交/合并主干、签名打包或部署。真实联调和生产验收不适用，需另立实施范围。

接续：本目录 npm run dev -- --host 127.0.0.1 --port 4387 --strictPort。检查 npm run build。当前服务由 Agent 保持运行；关闭服务后本机链接不可用，源码和构建输出保留。
