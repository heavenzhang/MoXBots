Only the first subsequent closed-schema application frame fixes Agent or Host-management mode. Explicit Controller reservations remain management channels. Later cross-profile frames poison that channel; roles do not come from canonical TLS direction.
- Agent calls and returns do not reuse management channels. A management request encountering an already installed channel to its exact target returns `HOST_MANAGEMENT_TARGET_BUSY`; it leaves the existing channel intact. No active Agent result channel is closed to make room for management.
- The original management controller may temporarily own the actor socket for its original bounded request. Unrelated channels, route controls and other request errors enter a FIFO queue with a shared MemoryBudget lease per frame. The original actor processes them after management success, channel error or timeout. Errors are correlated against management control IDs; another Agent's permit error is deferred. Queue capacity is bounded at 256 messages and socket byte budget; capacity loss fails the outer connection explicitly rather than silently skipping a consumed frame.
- The outer 30-second request deadline remains unchanged. If cancellation interrupts the management future, an actor-owned exact channel checkpoint retires only that management channel and attempts the original bounded close. Deferred frames and their leases survive this cancellation. A subsequent management request cannot overtake pending deferred frames. Legacy execute callers retain their original function signature and error behavior.
- Original Agent pair sequences, management frame sequences/nonces, byte budgets and management retirement checks remain active. Provisional management bookkeeping is released once an Owned channel selects Agent mode, avoiding exhaustion across ordinary Agent channel lifetimes.
- Lead-owned return recovery interfaces are connected in RouteRebound: current ready peer/channel check, source rebound acknowledgement, target no-terminal rebound probe, then the original target event send path. Return registry behavior and service real-socket acceptance are lead-owned.
