群上下文只来自显式群消息与结果，最多24KiB；旧私聊与其他项目不展开。每个明确群请求当前拥有一个独立目标 Session；后续 UI 须把这些参与会话归到群组，不能继续铺满全局列表。本批未承诺同一 Bot 长会话复用，未新增执行队列/后台调度/群Store。

限制：128条发送记录、8个未结请求上限、8KiB输入、32KiB结果摘录；总 ledger 1MiB，发送前预留 JSON 转义后的结果空间，因此实际可接纳并行数也受剩余字节额度约束。已满时明确拒绝，不静默裁剪任务或历史。完整结果留在原目标会话，摘要记录完整 payload SHA256以识别摘录之外的重复冲突。
