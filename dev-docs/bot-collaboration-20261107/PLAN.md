## 现有owner内的实现契约

- 原Admin Session来源决定是否继承；禁止调用者覆写项目快照/继承开关。Rust只转发布尔值，不拥有项目状态。
- 目标原Session出生入口重读来源Session和当前config/projects；只有本地内部来源，且来源/目标均为当前有效项目成员并拥有唯一有效工作区，才编译projectSpace。来源会话归档、项目归档/删除或配置读取失败均拒绝，不降级成无项目执行。
- 原项目说明、资料、revision冻结不变，目标botId/name/icon/workspace按接收方重新绑定；原Agent snapshot继续决定模型、工具、权限。SessionStore沿原准备/发布/回滚/冷读规则持久化，无新Store/队列/数据库字段。
- 首次Inbox不会走desktop query准备，也被动态项目历史排除；因此将固定背景用现有有界renderProjectContext加入同一个send.request隐藏提醒，保留气泡仅显示原任务。不开动态历史聚合，不合并私人记忆。
- 既有send/result、Stop及未知ACK不重派保护保持。普通无项目、外部CLI、跨设备保持原路径；不读取远端source ID对应的本地资料。
- 本批无新通信模式、状态owner或进程；持久群关系和任务验收仍未实施，不添加人工验收/返工常驻控件。

部署单元desktop/macOS-arm64/updater/sharedCI/main仍唯一由01a12bc2-907a-7702-b6dd-788225c5dfe4协调；本分支不运行共享CI、正式构建、安装或分配版本。无cloud/mobile/website发布。本地源码、模拟、真实联调、main、制品和原生验收分开记录。
