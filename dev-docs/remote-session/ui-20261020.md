# REMOTE-UI-20261020 — remote session presentation

Screenshot regression: tool cards had large inset blocks, Read output exposed a
truncated SDK JSON envelope, composer/long metadata could overflow horizontally,
and raw identity UUIDs consumed a full header row.

Target projection now reuses the existing local SDK text parser before the
2,000-character cap. The text body, stderr, real error/running status, empty
result and visible truncation are preserved without projecting raw inputs or
thinking. The shared parser is moved without behavior changes; existing local
imports remain compatible through re-export. The controller renders canonical
text exactly once, preserving JSON file content verbatim.

Remote UI uses shared CollapsibleTool and ExpandableContainer with plain text,
semantic tool icons/status and tighter spacing. Long content and composer wrap
within the viewport. IDs remain in the subtitle tooltip. No remote path is
resolved against the local workspace, and no file or media action is introduced.
No protocol, runtime, account, operation ledger or approval behavior changes.
