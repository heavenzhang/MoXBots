# MB-BOT-CORE-20261106 · 以 Bot 协作为核心的桌面端

用户目标：简洁、以 Bot 协作为核心。日常只需交代目标、查看结果、处理真正需要判断的事项。

## 产品主线

用户选择负责 Bot → 在协作对话交代目标 → 负责 Bot 分解并协调成员 → 成员提交成果 → 负责 Bot 核验、汇总 → 用户确认需要其判断的事项。

主界面默认两栏：左侧 Bot 与协作入口，中央当前对话。Bot 有稳定名称、头像、职责和真实工作状态，点击进入其当前工作；历史对话收在 Bot 内。协作显示主题、负责 Bot、必要成员和重要状态。项目保留为协作上下文与资料归属。任务、成果、成员细节按需打开，右侧目录和执行日志保留原入口但不常驻展开。

正常执行以一行状态摘要呈现；交接与回报是可展开事件；阻断明确说明影响和可执行的下一步。收到消息、任务返回、成果生成和验收通过分别显示各自事实。

## 机制与验收边界

协作呈现复用当前 Session/项目上下文；执行继续由原 Inbox、SessionEngine、native hooks 和任务账本准入。Bot 个人记忆不自动合并，群成员不会因此获得额外文件或工具权限。外部发送、付费或扩大权限继续按原授权判断。Stop、unknown、原任务验收与恢复保护不改；收到任务不表示执行成功，成员结束不表示整个任务验收。

ProjectSpace/Session/Task 的具体新增字段、命令、并发裁决与持久化owner是BC-02实施前需要明确的契约；本轮是路线收敛和主干组合准备，没有新增群组运行时、通信模式或第二套Store。本文件不替代该契约讨论。
