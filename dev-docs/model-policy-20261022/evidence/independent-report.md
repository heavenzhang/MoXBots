- 搜索改变清除选择；只将当前7项均衡结果批量暂停，其余快速模型保持启用。
- 保存注入失败后状态未变、确认仍保留；解除故障再次确认成功。
- 撤销遇到并发变更时拒绝覆盖并明确反馈。
- 目录读取失败时禁用开关；解除故障点击重试恢复23项。

## 必须修复

UI-01（P2）：列表模型选择复选框为13×13裸input，无扩大命中label。1440实测{x:272,y:478.75,width:13,height:13}；390图中还单独居中一行。点击模型名不选择。要求：≥32px命中区、键盘可用，在窄窗与模型信息保持清楚关联。

UI-02（P1）：通过键盘Enter打开“暂停自动候选”确认框，document.activeElement仍为背景“暂停”按钮；role=dialog计数0。确认框未建立首焦点和模态语义。Escape关闭和归焦观察通过。要求：合理首焦点、模态语义、焦点不得落入背景操作，关闭回原入口。共享ConfirmDialog现状来源不改变受影响路径必须修复的结论。
