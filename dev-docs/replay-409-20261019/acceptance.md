## 实现与边界

- QueryRequestGuard 的原准入行保留完整拒绝响应，重复请求只读证据，不取得 lease。每条 error body 仍限16KiB/1s，每个 guard 的诊断快照总额限1MiB；容量用尽仍保留原准入证据并拒绝重放。
- 两层 ContextRecovery/ModelFailover 都遵守同一行为，失败流及本地安全错误不会变成可重放错误。未知/超大/残缺 error body 保持安全停止。真正上游409保留原错误；本地409用 recovery=blocked 标识。
- 快照只在原 Query 内存存活，不写入业务历史、配置或磁盘。请求在进行中、身份不匹配或scope已封锁时不返回该快照。重复请求返回明确的安全错误code/marker及原始HTTP状态/原因；它不改变Goal原有安全暂停分类。返回原错误并不证明业务任务完成，也不会让不可用的供应商恢复。
